Introduction to HTML

What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages, defining their structure and content using elements like text, images, and links.

Markup Language

A markup language is a computer language that uses tags to define elements within a document.

HTML stands for HyperText Markup Language.

It is the standard language used to create webpages.

HTML defines the structure of a webpage using elements and tags.

Inline Elements

Inline elements do not start on a new line and only take as much width as necessary.

Inline elements fit within block elements.
